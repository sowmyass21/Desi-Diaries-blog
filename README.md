# Desi Diaries – Blog Website

Desi Diaries is a blog website that showcases Indian culture, food, and traditions.  
It is built using React (Vite) for the frontend.

## Live Demo

Deployed on Render:  
https://desi-diaries-blog.onrender.com

## Tech Stack

- React + Vite
- HTML, CSS, JavaScript
- Axios / Fetch for API calls (if any)
- Git & GitHub for version control

## Features

- Responsive UI for desktop and mobile
- Blog-style pages for culture, travel, and food
- Clean, simple navigation
